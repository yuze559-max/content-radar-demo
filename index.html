  2. 收益承诺：“涨幅、暴涨、稳赚”等表述必须删除或增加不确定性说明。
  3. 未核验来源：来源数 < 2 或仅为自媒体 / 股吧，需补源或降级。
  4. 相似度超限：与原文相似度 ≥ 0.75 必须人工改写。
  5. 英文候选：发布前逐句核对事实、数字与语气。

⑤ 当前局限

Demo 边界保持诚实可解释

  1. 部分多源聚合仍依赖人工补源。
  2. X 完整近 30 天数据需官方 API；当前为镜像快照 + 真实推文样例。
  3. LLM 英文候选可能出现事实或语气偏差。
  4. 策略迭代面板目前使用静态演示数据。
  5. 复杂事件的去重边界仍需人工判断。
